# Changelog

This file contains concise curated summaries of `main` releases, tagged `v<VERSION>` (`0.0.0.0` predates the branch ladder). Nightly builds are recorded only as GitHub prereleases, and beta (`stable`) candidates publish no GitHub release. GitHub Releases own the detailed history of what they publish.

The owner writes each entry, or confirms an agent's draft, in an ordinary pull request into `dev` while preparing a `main` release, so the entry rides the ladder with the candidate and is present when `stable → main` checks release notes. No other pull request edits this file.

Versioning follows the repository's `FINAL.MAJOR.MINOR.PATCH` scheme rather than SemVer. [`RELEASE.md`](RELEASE.md) owns the version rules; pre-1.0 releases are prereleases.
